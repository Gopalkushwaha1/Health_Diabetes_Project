# 🩺 Health Diabetes Prediction Model

A machine learning project that predicts whether a person is likely to have diabetes based on various health-related features.

The project uses a diabetes dataset obtained from **Kaggle** and follows a complete machine learning workflow, including data preprocessing, exploratory data analysis, feature selection, model training, and evaluation.

## 📌 Project Overview

Diabetes is a common health condition that can be influenced by several factors such as glucose level, blood pressure, BMI, age, and other health indicators.

The objective of this project is to build a machine learning model that can analyze these factors and predict whether a person is likely to have diabetes.

## 📊 Dataset

The dataset was obtained from **Kaggle**.

It contains health-related information such as:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age
* Outcome

The `Outcome` column is the target variable:

* `0` → Non-diabetic
* `1` → Diabetic

The project follows these major steps:

## 🧹 Data Preprocessing

The dataset was inspected for missing values, incorrect data types, and inconsistent data.

Approximately **5% missing values** were identified and handled during the preprocessing stage.

The data was then prepared for machine learning by:

* Cleaning the dataset
* Handling missing values
* Selecting relevant features
* Preparing the target variable
* Splitting the dataset into training and testing sets

An **80:20 train-test split** was used for model evaluation.

## 🤖 Machine Learning Models

Multiple classification algorithms were implemented and compared.

### 1. Logistic Regression

Logistic Regression was used as one of the baseline classification models.

It predicts the probability of a binary outcome, making it suitable for predicting whether a person is diabetic or non-diabetic.

### 2. Decision Tree

A Decision Tree model was used to identify decision rules based on the input health features.

It is easy to interpret and provides a tree-like structure for classification.

### 3. Random Forest

Random Forest was also implemented.

It combines multiple decision trees to improve prediction performance and reduce the risk of overfitting compared with a single decision tree.

## 📈 Model Evaluation

The models were evaluated using:

* Accuracy
* Confusion Matrix

The models were compared based on their performance on the test dataset.

The best-performing model achieved approximately **90% accuracy** on the evaluated dataset.

> Note: Model accuracy can vary depending on preprocessing, random state, feature selection, and dataset splitting.
